# Pharmaceutical Sales & Prescription Analysis

## 📌 Project Overview

An end-to-end data analytics project analyzing pharmaceutical sales and prescription data using Python, SQL, MySQL and Power BI.

The project focuses on understanding sales performance, revenue, profitability, prescription trends, product performance and geographic patterns.

## 🎯 Objectives

- Analyze pharmaceutical sales performance
- Identify revenue and profit trends
- Analyze prescription patterns
- Evaluate drug and product performance
- Analyze regional sales performance
- Identify key business KPIs
- Build interactive Power BI dashboards
- Generate actionable business insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- MySQL
- Power BI
- DAX
- Jupyter Notebook

## 📊 Project Workflow

### 1. Data Cleaning & Preparation

Performed data cleaning and preprocessing using Python and Pandas.

### 2. Exploratory Data Analysis

Analyzed sales, revenue, profit, prescriptions, products and geographic performance.

### 3. SQL Analysis

Used MySQL to perform business analysis using:

- SELECT
- WHERE
- GROUP BY
- HAVING
- JOIN
- CTE
- CASE
- Subqueries
- Window Functions
- RANK()
- ROW_NUMBER()
- DENSE_RANK()
- LAG()

### 4. Power BI Dashboard

Created interactive dashboards containing:

- KPI Cards
- Revenue Analysis
- Profit Analysis
- Prescription Analysis
- Product Analysis
- Geographic Analysis
- Trend Analysis
- Slicers and Filters
